# Synthetic Principal-Curve Datasets

This directory contains the synthetic datasets used for the principal-curve
simulation scenarios in the manuscript:

- `spiral_i.csv`
- `spiral_ii.csv`
- `heart.csv`
- `butterfly.csv`
- `pedal.csv`
- `elvis.csv`

Each CSV contains the sampled curve parameter `lambda`, noisy observations
`y1`, `y2`, and optionally `y3`, and the corresponding noiseless true-curve
coordinates `true_y1`, `true_y2`, and optionally `true_y3`.

The files are generated by:

```bash
python examples/generate_synthetic_datasets.py --output data/synthetic --seed 42 --n 120
```

The generator uses Gaussian noise in the normal space of each true curve.  The
default seed is `42`, and the default sample size is `120` observations per
scenario.  The `metadata.json` file records the noise level, dimension, and
lambda range for each scenario.

The Elvis scenario is generated from a deterministic cubic B-spline with
hard-coded control points in `examples/generate_synthetic_datasets.py`, so no
external data file is required.
